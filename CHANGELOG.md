# Changelog

## 1.2.0 — 2026-11-17

- Seven new playbooks: financial analysis, machine learning, scientific research, mobile app work, spreadsheets and slide decks and documents, browser and computer automation, creative work. Twenty in total. None has been tested yet.
- README: a section on which models the skill is for and how each gets better.

## 1.1.1 — 2026-11-17

- Risk gate: a definition in the project's documentation does not settle which field the requester meant.
- README: test results updated for all four models on the current version.

## 1.1.0 — 2026-11-17

- Risk gate: check every field or meaning a condition in the request could refer to, and treat items that only some readings include as doubtful.
- Added an MIT licence and this changelog.

## 1.0.0 — 2026-11-17

- Five difficulty tiers with numbered steps for Tiers 3 to 5.
- A separate four-step risk gate for destructive, shared-system, outward-facing or paid actions.
- A "stay inside the request" step: see a bug fail before fixing it, and report related faults instead of fixing them unasked.
- Eight reference files, including 13 domain playbooks.
- Tested with Opus 5.5, Sonnet 5.5 and Haiku 5.5; results are in the README.
